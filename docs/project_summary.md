# AI-Powered Options Trading Platform

This project is an educational web platform for creating option strategies, backtesting them using historical Nifty data, and receiving AI-based suggestions.

## Team Roles
- Person J: Frontend and UI
- Person C: Backend, backtesting engine and AI/ML model
- Person S: Dataset preparation, QA testing and documentation

## Disclaimer
For educational analysis and paper-backtesting only. Not investment advice.
